# CM Route — «Не потерять пациента»

Прототип для кейса СМ-Клиники. Система:
- читает протокол УЗИ и находит клинически значимые находки;
- показывает их администратору (он же врач) с объяснением, почему сработало;
- после подтверждения ведёт пациента до консультации профильного специалиста нейтральными уведомлениями и напоминаниями.

Маршрут заканчивается, когда **пациент дошёл до врача**.

- **Только локально.** Внешние LLM и облака не используются, распознавание работает на CPU.
- **Обезличено.** Вместо ID пациента хранится псевдо-ID (HMAC). ФИО и телефоны вырезаются из текста.
- **Без диагнозов.** Система отмечает отклонение и предлагает маршрут, решение остаётся за врачом.
- **Пациенту — без находок.** Только «плановая консультация», «незавершённый маршрут обследования».
- **Интеграции — заглушки.** МИС 1С, расписание, push и SMS имитируются; контракты описаны ниже.

Как устроено по блокам и как тестировали — в **[ЛОГИКА_РАБОТЫ_И_ТЕСТЫ.txt](ЛОГИКА_РАБОТЫ_И_ТЕСТЫ.txt)**.
Открытые вопросы к медэксперту и история версий — в **[ПОМЕТКИ_ДЛЯ_КОМАНДЫ.md](ПОМЕТКИ_ДЛЯ_КОМАНДЫ.md)**.

## Быстрый запуск (демо)

Нужен Python 3.10 или новее.

**Windows.** Распакуйте архив и дважды щёлкните `start_demo.bat`. Скрипт:
1. создаст окружение;
2. поставит зависимости (в первый раз 1–3 минуты);
3. откроет http://localhost:8000.

**macOS / Linux:**
```bash
./start_demo.sh
```

**Вручную (Windows PowerShell)** — из папки, где лежит `requirements.txt`:
```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
$env:CM_ENV="demo"
.venv\Scripts\python -m uvicorn app.main:app --port 8000
```

**Вручную (macOS / Linux):**
```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt
CM_ENV=demo .venv/bin/python -m uvicorn app.main:app --port 8000
```

После запуска откройте http://localhost:8000.

**VS Code:** откройте папку проекта, создайте окружение и поставьте зависимости (`python -m venv .venv`, затем `.venv\Scripts\python -m pip install -r requirements.txt`), потом нажмите F5 → «CM Route: демо». Конфигурации запуска лежат в `.vscode/launch.json`.

**Docker:**
```bash
cp .env.example .env        # заполнить секреты
CM_TARGET=demo docker compose up --build
```

### Что показать на демо
1. Выберите роль «Администратор» и нажмите «Демо-данные»: в очереди появятся находки.
2. Откройте маршрут. В карточке видно:
   - подсвеченную фразу, правило, атрибуты и уверенность;
   - блок «Не сработало и почему».
3. Нажмите «Подтвердить». Затем «Открыть кабинет пациента» или «Сменить роль» → «Пациент». Пациент видит:
   - нейтральный баннер;
   - уведомления;
   - телефон с пушами и SMS;
   - кнопки записи.
4. Прокрутите модельное время кнопками +24 ч / +72 ч / +7 д: придут напоминания, на 7-й день админу придёт задача позвонить.
5. «Настройки»:
   - автоотправка без проверки, включая свои правила и кнопку «Проверить на текущих маршрутах»;
   - сценарий уведомлений с проверкой нейтральности текстов.
6. «Словарь»: ручное добавление терминов, органов, находок и исключений. Действует сразу.

## Как это работает

```
МИС / файл / интерфейс
  → обезличивание
  → разбор текста (pymorphy3, опечатки)
  → находки по правилам словаря: термины и «ЧТО + ГДЕ»; фильтры: отрицания, анамнез, неуверенность,
    исключения, рекомендации, пороги размеров и BI-RADS
  → второй контур (TF-IDF + логрегрессия): подсказки «проверить», без автоотправки
  → маршрут по матрице: одна карточка на специалиста; экстренное — сразу персоналу
  → проверка администратором или автоотправка по правилам
  → нейтральные уведомления и лестница напоминаний
  → запись → приём ✔
```

## Качество (словарь 0.6, только правила)

| Набор | Находок | Пропуски | Ложные | Нормы с ложным срабатыванием |
|---|---|---|---|---|
| Выданные протоколы (89) | 68 | 0 % | 8,1 % | 4 из 36 |
| Протоколы из открытых источников (57) | 34 | 5,9 % | 15,8 % | 3 из 26 |

- Словарь писали по выданным протоколам, поэтому цифры на них оптимистичны.
- Все оставшиеся ошибки — вопросы клинической политики для медэксперта.
- Синтетика в метриках не участвует.

Подробно, включая кросс-валидацию второго контура, — в `ЛОГИКА_РАБОТЫ_И_ТЕСТЫ.txt`.

```bash
CM_ENV=demo python scripts/evaluate.py data/real/protocols.jsonl --no-ml   # только правила
CM_ENV=demo pytest -q tests
```

## Настройка без программиста

- **Новая находка или синоним:**
  - вкладка «Словарь» → «Ручное добавление» (хранится в базе);
  - или блок в `config/findings.yaml`, подхватывается без перезапуска.
- **Исключение** («тромб» рядом с «аортой» — не тромбоз вен ног): «Словарь» → «Исключения».
- **Автоотправка без проверки:** «Настройки». Режимы: все плановые / врач УЗИ согласен / выбранные специалисты / свои правила.
  Экстренные находки и находки второго контура пациенту автоматически не уходят никогда.
- **Тексты и напоминания:** «Настройки» → «Сценарий уведомлений». Ненейтральный текст сохранить нельзя.

## Контракт с МИС

`POST /api/events` с заголовком `Authorization: Bearer <CM_MIS_TOKEN>`:
```json
{"event_id": "uuid", "type": "protocol.signed", "protocol_id": "УЗИ-2026-000123",
 "patient_id": "ID-в-МИС", "study_type": "УЗИ органов малого таза", "study_date": "2026-08-26",
 "text": "…текст протокола…"}
```

| type | Что делает сервис |
|---|---|
| `protocol.signed` | Анализ и создание маршрутов |
| `protocol.corrected` | Пересчёт без дублей; пропавшие находки закрываются |
| `protocol.cancelled` | Маршруты протокола закрываются, сообщения отменяются |
| `appointment.booked / cancelled / completed / no_show` | Смена статуса маршрута |

Повторный `event_id` ничего не делает. Остальные API — в `app/main.py`; в демо-режиме есть `/docs`.

## Режимы и секреты

- `CM_ENV=demo` включает:
  - модельное время;
  - кнопку «Демо-данные»;
  - работу без токенов.

  Использовать только на синтетике.
- Рабочий режим без секретов не стартует. Скопируйте `.env.example` в `.env` и задайте `CM_PSEUDO_SALT`, `CM_API_TOKEN`, `CM_MIS_TOKEN` (≥ 32 символов).
- Пилот разворачивается только внутри контура клиники: это медицинские персональные данные (152-ФЗ).

## Данные и модель в репозитории

Для работы всё лежит в репозитории:
- `data/real/` — выданные протоколы;
- `data/web/` — протоколы из открытых источников;
- `models/second_layer.joblib` — обученный второй контур.

После клонирования работают все функции: правила, второй контур, метрики и переобучение (`CM_ENV=demo python scripts/train.py`).

⚠ В выданных протоколах есть даты рождения и имена врачей, поэтому **держите репозиторий приватным** (Settings → General → Danger Zone → Change visibility → Private).

## Ограничения

- Данных мало (146 размеченных протоколов), разметку делал не врач.
- Пороги и маршруты подобраны по учебникам, их должен подтвердить медэксперт.
- Для PDF-сканов без текстового слоя нужен OCR (локальный Tesseract), в прототипе его нет.
- Пуш и SMS — заглушки. Настоящая отправка идёт через приложение или ЛК клиники по тому же контракту `notify.to_patient`.
